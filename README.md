# Expense Tracker — Daily & Monthly
A personal expense tracker that records daily spending by category and shows where the money actually goes — daily totals, monthly totals, savings against income, and each category's share of overall spending. All data is stored in the browser, so it works offline with no account and no server. 

## Features

- Add an expense with a date, category and amount
- Monthly income field, used to calculate savings
- Entries list showing date, category and amount
- Delete any entry with the × button
- View a single day's entries, jump to Today, or show all
- Daily Summary — total spent per day, with the number of expenses
- Monthly Summary — total spent per month, with the number of expenses
- Savings — income minus spending, shown as an amount and a percentage
- Totals by Category — total spent in each category
- Grand Total across all days
- Export to CSV
- Data persists in `localStorage` — no account, no backend

## Tech

Plain HTML, CSS and JavaScript in a single `index.html`. No frameworks, no dependencies. Hosted on GitHub Pages.
